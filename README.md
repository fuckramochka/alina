# Софія Київська — шкільна вебпрезентація

Інтерактивна навчальна презентація українською мовою про історію, архітектуру й мистецькі скарби Софійського собору в Києві.

**Авторки:** Мамчур Аліна та Якимчук Валерія, 7-Б клас.

## Перегляд

Відкрийте [вебпрезентацію](https://fuckramochka.github.io/alina/) у сучасному браузері. Стрілки ← → перемикають слайди, клавіша F вмикає повноекранний режим. На слайді з відео є локальне відео, вбудоване у плеєр.
