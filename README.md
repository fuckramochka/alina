# 🥒 Огірковий Тріумф | Агро-проєкт учениці 7-Б класу Мачур Аліни

> Шкільний дослідницький проєкт про те, як вирощувалися огірки до 25 липня, великий збір врожаю, першу хрумку пробу та закрутку 4 банок на зиму!

## 🌟 Про проєкт

Цей інтерактивний сайт-презентація створений у яскравому смарагдово-зеленому стилі для наочної демонстрації шкільного агрономічного дослідження:
- **Авторка:** Мачур Аліна, учениця 7-Б класу
- **Період дослідження:** травень – 25 липня 2026 року
- **Ключова дата:** 25 липня — день збору врожаю
- **Результат:** смачна дегустація свіжого огірка та закрутка **4 фірмових банок** хрумкої консервації на зиму!

## ✨ Особливості веб-сайту

- 🌿 **Сучасний соковитий зелений дизайн**: Glassmorphism, анімації падіння листочків, адаптивність під мобільні телефони та комп'ютери.
- 📸 **Реальні фотографії процесу**:
  - `photo_2026-09-04_07-12-14.jpg`: Пишні огіркові грядки з вертикальною шпалерою.
  - `photo_2026-09-04_07-12-04.jpg`: Повний пакет зібраних огірочків 25 липня.
  - `photo_2026-09-04_07-12-20.jpg`: Свіжий пухирчастий огірочок у руці під час дегустації.
- 🫙 **Інтерактивна вітрина 4 банок**: кожна баночка відкривається за кліком та розкриває свій фірмовий рецепт і секрет хрускоту.
- 🔊 **Звукові ефекти (Web Audio API)**: реалістичний синтез звуку хрускоту огірка при натисканні кнопок.
- 🖥️ **Режим показу слайдів**: спеціальна кнопка *"Слайд-шоу для класу"* з навігацією стрілочками для демонстрації на шкільному проекторі або інтерактивній дошці!
- 🏆 **Почесний сертифікат 7-Б класу** із запуском святкового салюту/конфеті.

## 🚀 Як відкрити локально

Просто відкрийте `index.html` у будь-якому сучасному веб-браузері (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
